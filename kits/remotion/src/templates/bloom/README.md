# Bloom · 爱人如养花 · 婚礼开场

`VVV-Bloom` 是一款黑底手绘贴纸与柔光羽化风格的婚礼大屏开场片，16:9（1920×1080，30fps），全片共 **214 拍**，按默认配乐 *Skyline*（`music/mixkit-skyline.mp3`，84 BPM，下载后使用；可通过 `npm run music` 拉取）的节拍排布，约 **2 分 35 秒**。模板内置全部纯代码 SVG 手绘插画与动画特效，共有 **20 个写真/抠图插槽（标准容量 55 张）**。

## 章节顺序与节拍排布

1. **Prologue · 片头引子**（2 拍）：`我们` + `的故事即将开始...` 手写渐显。
2. **Born · 我们出生啦**（5 拍）：两翼家乡地标贴纸与斜置出生年份，晃动的童年照立牌与城市名。
3. **ParentsGardeners · 爱人如养花**（6 拍）：`爱人如养花` / `我们最好的花匠是 爸爸妈妈` + 跳动爱心，4 组竖椭圆家庭老照片依次入场。
4. **Wing · 在父母的呵护下**（6 拍）：旋转黑胶唱片、旋转动态箭头、两行手写文案、4 组童年抠图白边贴纸、左下与右下角闪烁星星。
5. **GrowingHappily · 茁壮成长**（6 拍）：左侧 2 张男生照 + 右上 `我们幸福地` + 右下 2 张女生照，左下旋转小太阳并列 `茁壮成长`。
6. **ThanksParents · 感恩父母**（9 拍）：左上角绿芽插图、两张粉边横版父母合影与两行感恩文案。
7. **MeetQingdao · 相识青岛**（11 拍）：先打字过渡 `时间来到 2021年...`，再展开粉色青岛地标胶囊、青年立牌以及 3 组动态插画（黄色爆发线、跳动爱心、动态纸飞机与蓝色波浪线）。
8. **LoversPets · 恋人与宠物**（11 拍）：`2023 11 20 我们成为了 恋人`，无背景人物抠图与宠物贴纸按顺序渐进弹出，右下角动态爱心。
9. **DaysCounter · 携手同行天数**（7 拍）：`我们携手同行了` 渐进擦除后，粉色天数数字整体一起弹出。
10. **MemoriesSection · 在这些日子里**（27 拍）：「庆祝生日」「看演唱会（带抖动音符）」「我们的第一套写真」，柔光羽化遮罩照片以纵向影像带方式切换并带轻微抖动。
11. **TravelSection · 一起去旅行**（48 拍）：两侧 `一起去` / `旅行`，中间 6 站（云南、新疆、青岛、杭州、长白山、大西北）柔光羽化照片以纵向影像带切换、带轻微抖动（包含单竖、宽横、上下双拼、左右双拼），底部地区文字缩放出现。
12. **RitualsSection · 仪式感**（9 拍）：左侧四行文字渐进出现，出现 `仪式感` 时右侧柔光羽化照片以擦除方式出现。
13. **SeasonsPoem · 四季诗意长句**（11 拍）：春夏秋冬四行感悟逐行渐显。
14. **ProposalSection · 求婚啦**（10 拍）：出现 `「 求婚啦 」` 时右侧显示柔光羽化求婚照，并以纵向影像带切换、带轻微抖动。
15. **EngagementSection · 我们订婚啦**（15 拍）：出现 `「 我们订婚啦 」` 时右侧显示订婚照，结合影像带与擦除切换，柔光羽化遮罩并带轻微抖动。
16. **LicenseSection · 我们领证啦**（6 拍）：先渐进出现 3 张柔光羽化领证照，再在右下角出现 `我们领证啦`。
17. **NewChapterSection · 新篇章**（11 拍）：左侧大主婚纱照（柔光羽化+轻微抖动），右侧 8 行文案渐进出现。
18. **ThanksGuestsSection · 感谢宾客**（8 拍）：双张柔光羽化婚纱照与底部渐进致谢文案。
19. **FinaleSpotlight · 聚光灯尾声**（6 拍）：左侧粉色两行字渐进出现，右侧柔光羽化聚光灯婚纱照定格收尾。
